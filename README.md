# Void of Undying Stars

A 2D action-platformer inspired by *Hollow Knight*, developed using Unity and C#. Explore the map, fight enemies, collect money, and master your abilities before facing the final boss.

## About the Game

Void of Undying Stars is a game project I created from scratch, including the programming and visual assets. The game focuses on responsive movement, combat, and resource management.

Players can run, dash, double jump, and attack enemies. By dealing damage, players refill their Focus bar, which can then be used to heal. At the end of the map, a boss awaits, featuring two unique abilities and a large health pool.

## Features

- **Main Menu:** View the controls and start the game.
- **Movement:** Walk left and right, dash, and double jump.
- **Combat:** Attack enemies using the player's combat abilities.
- **Focus System:** Refill the Focus bar by hitting enemies.
- **Healing:** Spend Focus to restore health.
- **Collectibles:** Pick up money throughout the game.
- **Boss Fight:** Face a powerful boss with two abilities and a large amount of health.

## Controls

View the controls in the main menu before starting the game.

## Project Goals

The main goal of this project was to learn how to design and structure a working game that could be expanded with new features without making the code difficult to maintain.

I consider this goal a success. I am particularly proud of the code structure and how the different gameplay systems work together. While the visuals are an area I would like to improve, this project gave me valuable experience in game development, modular design, and building extensible gameplay systems.

## Getting Started

### Requirements

- Unity version compatible with the project.
- A compatible development environment for C#.

### Running the Project

1. Clone or download this repository.
2. Open the project through Unity Hub.
3. Select the appropriate Unity version if prompted.
4. Open the main game scene.
5. Press **Play** in the Unity Editor.
